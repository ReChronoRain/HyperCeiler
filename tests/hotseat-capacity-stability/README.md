# 解锁底栏图标数量的代码页生命周期

2026 年 10 月 26 日，os4-personal

确认并修复的代码缺口

- 容量补丁的 8 处原指令写入未登记现有 MADV_DONTNEED 页保护，Flutter 丢弃代码页时可能还原补丁
- 页保护安装由 Dock 动画维护触发，关闭玻璃时直接跳过，其他布局登记的页也缺少保护
- 容量补丁不在普通 Hook bank 中，仅配置刷新分支约每五秒重装，失效期间无法及时恢复

修改

- 启用前登记所有容量代码页，登记失败不发布新的补丁
- 沿用 NHK 的源映射、已知指令、原子写入、读回校验与持久恢复日志，不恢复固定地址或修改原生最大数量 getter
- Dock 玻璃关闭时，已有健康线程仍维护登记代码页所需的回收保护
- 容量健康检查接入已有约 500 毫秒的可绘制桌面维护轮次，不新增线程，不在渲染或手势回调中扫描
- HYOS 每轮只读现有原子配置快照，遵守授权及有效期，失效、禁用或拒绝时恢复原指令
- 健康轮次不扫描映射或写代码，只有实际修复进入原有写入校验，恢复旧的 RX 与回滚责任优先于新页登记
- 补充限频原因日志及精确功能名诊断，登记与读回成功只记录安装，不能作为 Hook 执行或最终画面已验证
