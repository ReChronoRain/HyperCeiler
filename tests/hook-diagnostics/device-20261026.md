## 自动化检查与限制

- 诊断规则 42 项、实际 Java 观察器 10000 次回调、实际 Native bank 10000 次健康检查、
  实际 MonitorLoop 的 200 次快循环/200 次稳定循环及 Room 迁移/保留 SQL：通过。
- `tests/log-diagnostics`、`tests/logcat-import`、`tests/home-render-performance`：通过。
- 通用 Native 套件中 `NativeHookBoundedReadsTest` 因 macOS 不提供 Linux-only
  `SYS_process_vm_readv` / `SYS_getdents64` 而无法编译；
  `DockNativeArm64Test` 要求 Linux+aarch64，本机跳过，未宣称整套通过。
- 没有自动最终画面验证器；直接绕过通用入口的 Java/Kotlin Hook、
  未暴露细分原因的 Native resolver、崩溃/安全模式归因仍有覆盖限制。
- 页面和报告保留未知/待验证，不把以上限制换算成“全部正常”。
