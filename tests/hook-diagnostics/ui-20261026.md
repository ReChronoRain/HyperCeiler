## 改动

- 系统桌面新旧主页 XML 都增加非持久化的智能诊断入口，显式打开模块内部诊断 Activity。
- 概览作为 PreferenceScreen 第一组中的独立 MIUIX 大卡片，四项数量使用两行两列排列。
  未采集时显示待采集，安装或执行没有算入最终效果已验证。
- 概览内保留证据分层说明，移除下方重复说明，环境与采集状态继续单独展示。
- 静态与动态页面描述只保留逗号，原始日志和导出技术标识不被格式化函数重写。
- Native 全部 231 个已定义槽位提供具体功能名，最近任务根据已识别 Plan 中的
  setting/action 区分圆角、标题高度、标题偏移、动画速度、卡片高度、各方向缩放和颜色。
- 旧 HCD1 槽位按冻结的 v1 元数据表命名，不把槽位编号当作地址。
  旧最近任务未记录具体 setting 时保留项目未知，不猜测。
- Java 已知规则翻译具体功能名，无法归属的规则明确标为用途未知。
