修改位于 `os4-personal`，范围是当前启用的 OS4 布局、图标与标题及其关联动画原生路径。
检查结果：启用路径没有按桌面版本保存的绝对函数地址表，但此前仍有“符号名命中并匹配函数序言”就安装的入口，以及已动态找到函数、回调却继续读取固定 Dart 栈槽的情况。本轮已补齐下面这些路径。

## 识别边界与失败处理

- 符号仍用于提供候选 owner 和完整扫描范围；“运行时特征识别”不等于完全不依赖符号名。缺少符号、特征不唯一或数据流不符时拒绝相关 Hook，不使用旧地址兜底。
- 扫描范围取完整符号表的下一个可执行 STT_FUNC，包含 size=0 和匿名条目，不盲信经常截断的 st_size。匿名子函数的栈槽按自身序言验证。
- 保留且明确区分 ARM64 指令／寄存器约定、原生保存区布局和 Dart VM ABI：tagged pointer +1、压缩引用 4 字节、Double／Offset 原始载荷、布尔值关系、对象头编码、原生 SP16 与 Dart 堆字对齐。这些不是特定桌面版本的业务字段偏移；VM ABI 改变时仍需重新验证。
- 文件夹标题 Insets 的 +8/+16/+24 相对关系由当前四个连续初始化 store 验证，起始字段仍动态读取。盒装 Double 的固定标签属于当前已验证的 VM 原始类型 ABI。
- 未启用的历史 feature-21 图标计算器与旧版 MIUI Java 实现，不作为当前 OS4 缩放入口。历史指示器配对分配样例仅在测试宏下编译。
- 新增识别拒绝原因以 WARN 限频输出，包含 feature、stage 和 reason；沿用 `HyperCeiler.HomeLayout` 内置日志采集通道，刷新／导出日志时进入数据库。
