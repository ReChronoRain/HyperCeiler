# October 26 device check

Release SHA-256: `c8ae6378a4786f10fed9d6578548dac7c4e441288151f6f5c8f0d14f1b48aa54`.
The APK was installed with `adb install --no-incremental -r`; the installed file
hash matched. Only the launcher was restarted. Its mapped native PT_NOTE/Build ID
matched the APK before any symbol-based scalar inspection. The engine's owner
PID matched the live launcher, and the rename observer was installed.

Device: model `24129PN74C`, Android 17, `OS4.0.0.22.XOCCNXM`, launcher
`8.01.02.8584-260918-10231931-R`. This is a different build/device from the
reporter's launcher 8593.

## Completed checks

- Four left-back, four right-back and four bottom-Home gestures from a controlled
  system Settings root, plus six launch/return interruption pairs. All 18
  sequences ended at the launcher. PID 12201 remained stable throughout.
- No new `/data/anr` entries, input-dispatch timeout, `FATAL EXCEPTION` or fatal
  signal appeared in the captured functional-test interval.
- A separate 22-second `strace` attached only to the launcher main thread during
  four warm launch/back cycles. It observed 39 `openat` calls, **zero `/proc/`
  opens**, and no captured file syscall exceeding 100 ms. Read buffers were not
  decoded. This directly checks the cmdline/maps hot path; it is not a frame-time
  measurement. The tracer detached cleanly and its temporary remote file was
  removed.
- A temporary folder-columns value of five rendered five visible columns. This
  proves this feature on 8584, not on the reporter's 8593.
- Temporary icon 80% / small-folder 75% requests reached native scalars as
  0.8125 / 0.75 (ordinary icons use the existing quantised encoding). Existing
  cached desktop geometry in the first screenshot did not immediately change;
  receiving these scalars alone is **not** counted as visual scale acceptance.
- After the user unlocked the phone, a deliberate launcher restart with those
  settings produced visibly smaller ordinary icons and small-folder background/
  previews. The folder still rendered five columns. Nine further gestures from
  the system Calculator (three left-back, three right-back, three bottom-Home)
  all returned home with PID 31122 stable. No new ANR or fatal/input-timeout log
  appeared in that interval.

The Settings test initially encountered historical MainSettings/MiuiSettings
layers; these were excluded from the completed root-page runs. A later scaled
run again encountered those layers and did not complete. The phone then locked.
Before pausing, all five temporary preference keys were verified restored
exactly, the debug writer was off, both native scale factors were back at 1.0,
and the launcher PID was still 12201. The resumed scaled test temporarily kept
the charging phone awake. At completion, the five preferences, debug writer,
screen timeout (600000 ms) and charging stay-awake setting (0) were verified
restored. A second deliberate launcher restart restored the cached original
icon geometry; the final screenshot shows the original sizes and glass Dock.
Final PID 2830 again matched the new native Build ID and engine owner PID.

Settings-stack runs. The two deliberate scaled/restoration launcher restarts
are separate from the stable-PID assertions within each test interval. This
device has no back-long-press action assigned, so it cannot establish
that the reporter's sidebar-long-press cancellation is fixed. There is no matched
pre-fix on-device frame timeline; neither subjective smoothness nor a numerical
frame-drop reduction is established. Launcher 8593 still needs its own test.
