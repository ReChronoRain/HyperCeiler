# OS4 底栏图标水平边距

新增入口位于系统桌面，布局，底栏图标，水平边距，使用独立开关与 0 至 100 dp 滑块，默认值 20 为中性基准，关闭或默认值保留系统原布局，数值增大时图标行向中心收拢

原生部分同时覆盖原有 HotSeatLayoutDelegate 布局消费路径及新版控制器的水平位置返回路径。新版从同一配置生产者、宽度消费、容量分支、RTL 索引和两条最终浮点运算中识别，函数地址、帧位置和调用目标均从实际指令解析，没有使用符号名或版本地址。独立 gate 与参数替换了原来对桌面左右边距的共用，桌面、文件夹及拖放的原有 workspace 参数不改。仅调整原始布局栈或保存的浮点操作数，没有新增 Dart 分配或保存堆对象。

实际桌面会缓存首次计算的位置，因此新版定位 Hook 纳入首次布局前的安装，修改设置后需重启系统桌面刷新，设置说明已注明。修复最终通用入口初始化可能覆盖专用 Dock 入口的问题。新定位分支在原生 bank 末尾追加两个用途明确的槽位，现有槽位编号和固定配置列不变。

配置通过同次 getAll 的 Cursor 可选 extras 读取，固定 schema 4 列数不变。HCL4 完整布局快照增加 HCHM 可选尾部，为 magic 0x4843484d，数量 1，范围 -20 至 80 的有符号 delta，共 12 字节。旧客户端忽略尾部，新客户端读取旧端点时使用零。缓存升级到 v19 并继续读取 v18，v18 没有独立参数时为零。

保留 HCS1 的固定 188 字节协议，未扩展独立 HYOS 伴随模块的布局负载。本功能在 APK 现有的主原生模块 HCL4 路径实现。
