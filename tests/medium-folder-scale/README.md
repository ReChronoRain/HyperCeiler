# Independent medium folder scale

The two switches and sliders are siblings of the existing scale controls in
Icons and titles. The native resolver identifies the current executable's span
arguments, size record, background aliases, preview helpers and padding call.
It never uses a launcher version, strategy class ID, stored address or stored
business-field offset.

The original Smi spans distinguish 3×1 and 1×3. The producer entry clears a
thread-local scalar observation before each invocation. The observation is
consumed once, in the matching frame, after the original geometry producers
finish. No Dart object pointer is retained and no managed call/GC PC is moved.
Both kinds use their own enabled/percentage pair even when large-folder scaling
is enabled. Unknown spans are not overridden. The existing small-folder path
remains available where its own executable contract validates.

The original six scale wire words remain unchanged. A trailing `HCMS` block
carries the two new pairs, with defaults disabled/100%. The cache is version 22
and continues to read versions 4–21. Provider extras carry the new keys from the
same physical preference revision as the original settings.

Run `python tests/medium-folder-scale/run.py` with a C++20 compiler (`CXX` may
name a compiler command). The anonymous executable fixture covers 9239 folder
geometry and return-animation links, independent function relocation, missing
or ambiguous graphs, wrong config producers and independent wire settings.
The existing `tests/folder-preview-return/run.py` suite also covers the original
7751/8583/8584 paths and their rejection cases.

Device validation: the haptic inventory returned 204 entries including support
statuses. Standard IDs 0/5 and vendor ID 521 successfully constructed both one-
and three-event effects without fallback. This verifies enumeration and effect
construction, not the physical sensation. Folder instruction/animation graphs
were verified against the device's 9239 image; visual and touch behavior still
require exercising the newly installed module.
