# OS4 桌面无限滚动

复用系统桌面，其他，无限滚动的现有开关，默认关闭，原有 OS2 和 OS3 的 Java 实现不变。

OS4 主 APK 原生路径从当前 Dart 可执行镜像识别桌面专用物理工厂、页面物理回退、弹簧构造器、ScrollPosition 的调用位置、手动拖动生产与清理、方向枚举及其常量池位置。没有通过私有符号、固定版本地址、固定字段偏移或对象 CID 选择目标。局部 native leaf bridge 的栈指令属于已验证 ARM64 Dart ABI，识别器跨这些内部片段继续校验原始托管调用链。

只有真实手动拖动且位于首尾边界或一页宽内的回弹越界区域的向外释放才准备循环，零速度释放依据原始滑动方向判定。非桌面调用、程序翻页、自动回弹、无拖动、单页、无效尺寸和不支持的图都保留原行为。原始工厂的模式保护继续执行。它创建原有弹簧对象时，限定到同一次释放的栈帧，在目标桌面页保留释放位移，再由原有 ScrollActivity 与原生弹簧收尾。起点与终点不再重合，目标页内收尾距离限制在视口宽度的百分之五到百分之二十五，避免首帧瞬间完成，也避免扫过中间页面。没有在 C 中调用 Dart、分配 Dart 对象、保留 Dart 堆指针、执行 Binder 或读写配置文件，也不注入或取消触摸事件。

一次释放使用同一份已授权状态，配置关闭后新释放保留原行为，已进入的释放可以完成。临时状态只含当前 Dart 栈及原调用链的数值标识、方向、边界、原始释放位移、视口和速度，下一次入口清除，构造回调先核对当前工厂的原始父帧、返回位置及指令识别出的工厂调用位置，再读取当前栈中的托管根。视口或边界变化则拒绝混用。速度按剩余收尾距离限幅，零速度保持零，阻尼及弹簧解算仍由原始构造器决定。关闭时不新装 Hook，已安装后只在页滑动末端清理该状态，非关联弹簧调用在汇编中跳过 C 回调。

父级滚动物理转发器也从当前镜像识别，与原始 goBallistic 入口核对相同虚表选择器，并验证仅替换 physics receiver，原样传递 metrics 和 velocity。入口沿最多八层经过验证的透明转发帧查找原始 goBallistic 根，不接受未知中间函数、错误返回位置、畸形栈链或错误的 metrics 根。回归覆盖独立搬移、不同转发层数和损坏链路，不使用固定符号或地址。

工厂的 metrics 参数在进入时写入原栈槽，随后被捕获到托管 Context，原槽会被配置对象覆盖。解析器关联原始 Context 分配调用、参数捕获及后续 physics 消费方，从活跃 Context 栈根解压 metrics。构造弹簧时重新读取该根，回归会主动覆盖旧参数槽并移动 Context，不接受旧栈槽仍有效的模拟前提。上下文字段、变量数量及栈位置来自当前指令，缺失生产者或消费者关系时拒绝识别。

诊断只保存标量值与代码位置，不保存可移动 Dart 对象。原有维护循环输出最后一次手动释放的拒绝原因及有限的尺寸信息，随后无拖动的自动收尾不覆盖这条记录。回调只尝试发布诊断副本，不等待锁、不写日志、不增加线程。

配置协议

- Provider schema 4 的固定列不变，单次 getAll 的可选 extras 增加 hc_infinite_scroll_version 和 home_other_infinite_scroll
- Snapshot 与 defensive copy、热重载恢复和 combined 内存发布保留该布尔值，沿用原有 epoch、revision 和 deadline
- 主 HCL4 回复在 HCHM 尾部后追加 HCIW magic 0x48434957 与布尔值 0 或 1，共 8 字节，旧读端忽略新增尾部，新读端读取旧服务时默认关闭，截断或非法值拒绝整个响应
- 接口 revision 为 20261027，capability bit 64，诊断可报告未加载新接口的 system_server
- 本地缓存 v20 追加相同尾部，继续读取 v19 与更早受支持缓存，缺失的无限滚动状态为关闭
- HCS1 固定 188 字节的独立伴随模块协议没有扩展，本次功能属于 APK 主原生路径

2026-10-27 间歇性滑动状态审计

用户说明类似断触的现象早于最新收尾动画且没有稳定触发步骤。本次没有回退动画，也没有修改或关闭自定义手势。检查时该设备自定义桌面手势关闭，未发现其主动消费普通横滑的证据。

原生产 finish 的宿主回归复现了另一处具体缺陷，原工厂因保护条件返回且未构造弹簧后，Pending 仍可能保留，后续普通 PagePhysics 复用相同 FP 时，即使调用已经不在原工厂中，只要旧 Context 栈槽与尺寸仍合法就会错误改写弹簧参数。修复前新增的断言失败，日志保存在 /tmp/hc-infinite-touch-fix-20261027/repro.log。本次从当前镜像关联工厂对原弹簧及其 helper 的调用返回位置，并核对原始父帧与返回位置，匹配失败先丢弃待处理状态，保留当前构造参数。没有保留 Dart 对象指针，没有增加原生分配、触摸事件注入、额外 Hook、线程或每帧日志。

新增回归覆盖工厂结束后的栈复用、错误父帧、错误返回位置、非工厂调用位置、缺失链路、直接与 helper 构造，以及独立搬移后调用位置重新识别。宿主复现证明旧代码有误用路径，不能据此认定它解释了用户所有偶发断触。仍需设备重复滑动和中断操作，真机结果单独记录。
